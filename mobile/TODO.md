# Resultados do CENA Mobile

- [x] **Aplicativo nativo como experiência principal.** O CENA Mobile deve ser implementado com React Native/Expo e interface nativa, sem WebView; o site existente continua como alternativa para ouvir em outros locais. O código deve ser portável para ser incluído em outro perfil Manus.
- [x] **Descoberta, busca e detalhes ligados ao catálogo CENA.** Usar as queries públicas existentes para filtrar por cidade, gênero e texto; abrir detalhes da faixa, artista e evento indicados; diferenciar carregamento, indisponibilidade, catálogo vazio e conteúdo de demonstração. Nunca apresentar amostras como uploads reais. A compilação Metro Android e o TypeScript passam; o backend Web expõe `scene.artistDetail` e mantém faixas, artistas e eventos ocultos fora das respostas públicas.
- [x] **Mostrar lotes de ingresso e merchandise em telas nativas.** Consultar somente os endpoints públicos `scene.eventTickets` e `scene.artistMerchandise`; renderizar preço, disponibilidade, estoque e destino externo sem abrir checkout nem criar reservas. Não expor dados de eventos/artistas ocultos ou itens indisponíveis; nenhuma mutation ou escrita de validação pode atingir o banco compartilhado. As tabelas `eventTicketLots` e `merchandiseItems` foram migradas no backend Web e os contratos foram testados.
- [x] **Player nativo persistente e fiel à faixa selecionada.** Reproduzir a URL de áudio da faixa aberta, manter controles entre telas, apresentar play/pause e progresso, pausar ao fim de uma faixa compartilhada fora do catálogo e não avançar para uma demo por coincidência de ID ou fallback.
- [x] **Conta, biblioteca e privacidade de ouvinte.** Continuar o perfil de ouvinte privado. A biblioteca, conta e ações autenticadas só serão habilitadas após existir um OAuth nativo seguro no backend; não simular login, não expor JWT em deep link e não chamar mutations sem sessão validada.
- [ ] **Perfil de artista e uploads reais.** Artista autenticado deve conseguir consultar/gerenciar perfil e enviar áudio/capa pelo endpoint validado do CENA; preservar validações de direitos, formato, duração, propriedade e moderação do servidor. Não enviar arquivo nem criar perfil real durante testes ou desenvolvimento deste pacote.
- [ ] **Importação e entrega Android.** Incluir identidade nativa da CENA, instruções e fonte sem credenciais, dados de produção, uploads, `node_modules` ou build local. O APK/AAB só será considerado entregue após a importação em projeto Manus Mobile gerenciado e conclusão do build Android no Dashboard.
